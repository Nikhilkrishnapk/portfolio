01 — About me

Turning ideas into smooth, scalable mobile apps.

I'm a frontend and mobile developer with over a year of professional experience designing and building responsive mobile and web applications with React Native, React.js, Redux and modern JavaScript (ES6+).

At Aakri Impact I build and maintain cross-platform React Native apps, including the Aakri Waste Management Platform user apps with 100K+ downloads on Android and iOS.

My day-to-day work covers component-based architecture, state management, RESTful API integration, Firebase services and payments with Razorpay. I also cut overall app load time by 30% through better state management and caching.

Beyond mobile, I've worked hands-on with Vue.js, Node.js, Express.js, MongoDB and PostgreSQL, and written automated tests with Playwright.

I care about clean, scalable code and enjoy working in collaborative, high-performing teams.
