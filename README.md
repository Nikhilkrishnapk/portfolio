## Run locally

It's a static site — no build step. Serve the folder with any static server:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000/.

## Project structure

```
index.html                     The whole page: markup, styles and logic
support.js, vendor/            Small runtime (React) that renders the page
images/                        Profile photo and project screenshots
Nikhil_Krishna_PK_Resume.pdf   Resume behind the "Download Resume" button
```
